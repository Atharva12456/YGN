YGN Methodology

Ethics Grade Score

What the Grade Means

The ethics grade is an educational transparency signal from 0 to 100, converted into a familiar letter grade. It is not an accusation, legal conclusion, endorsement, or misconduct finding.

Live scores use FEC campaign finance data when an API key is available. If live finance data cannot be matched, YGN falls back to deterministic static data so every member still has a stable, explainable grade.

Live Formula

  • Small-donor share, 30%: higher share of unitemized individual contributions improves the score.
  • PAC independence, 25%: lower PAC and party-committee dependence improves the score.
  • Donor concentration, 20%: lower reliance on very large itemized donations improves the score.
  • In-state support, 15%: more itemized support from the represented state improves the score.
  • Self and party independence, 10%: lower reliance on candidate funding and party committees improves the score.

Static Fallback

  • Public record completeness, 20%: public profile fields, district labels, and photo availability.
  • Constituency specificity, 18%: whether the member is tied to a district, at-large seat, or statewide seat.
  • Accountability baseline, 24%: deterministic public-record variation by member and state.
  • Disclosure baseline, 23%: deterministic variation tied to chamber and district context.
  • Service context, 10%: term-start context with bounded tenure effects.
  • Static variation, 5%: stable per-member spread so fallback grades do not collapse to one value.

Refresh Cadence

Backend ethics responses are stored in the same SQLite cache as the rest of the YGN API. The default cache TTL is 15 minutes, and the background refresh job rechecks stale entries when API keys are configured.

Grade Bands

A is 93 and above, A- is 90 to 92.9, B grades run from 80 to 89.9, C grades from 70 to 79.9, D grades from 60 to 69.9, and F is below 60.
