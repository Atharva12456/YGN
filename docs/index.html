Gerrymandering Risk Index

How the Score Works

The YGN index is an educational risk score from 0 to 100. It combines six signals: district shape, voting numbers, party control during redistricting, political and court events, social indicators, and individual donation patterns.

The current site ships a static state-level fallback so the map works on GitHub Pages. The structure is ready for deeper refresh jobs that replace static component values with district geometry, election returns, Census/ACS measures, redistricting records, and FEC data.

Component Weights

  • District shape, 25%: compactness and boundary complexity signals.
  • Voting numbers, 25%: seat-vote mismatch and efficiency-gap style signals.
  • Party in power, 15%: unified or divided redistricting control.
  • Political events, 15%: recent redraws, litigation, commissions, and remedial maps.
  • Social indicators, 10%: demographic and education sorting that can affect communities of interest.
  • Individual donations, 10%: concentration, in-state support, and small-donor balance.
